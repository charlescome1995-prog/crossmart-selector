🧪 Dev Runs — Selenium 单关键词抓取实测

这个页面是 backend/dev/asin_dev_scraper.py 的运行快照。

每次跑 python backend/dev/asin_dev_scraper.py --country US --keyword "..." 就会追加一张卡片：真实 Amazon SRP 截屏 + 摘要（ASIN 数 / Sponsored 数 / 价格区间 / 评分 / ASIN 样本）。

# 跑一个关键词抓取： python backend/dev/asin_dev_scraper.py --country US --keyword "storage bins" # 跑完产物自动镜像到 frontend/dev_runs/，push 后这里就显示： git add frontend/dev_runs/ && git commit -m "feat: dev scraper 截图" && git push

⚠️ Selenium 用 Edge 临时 profile，亚马逊登录/卖家精灵插件需要手动登录一次后保留 cookies 才能拿到 SS 字段。当前脚本只验证"能跑起来打开目标页面"。
